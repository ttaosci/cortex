# Changelog

Use this directory to record meaningful repository and workflow changes over time.

## Structure

- `cortex/changelog/entries/`: full changelog entry files
- `cortex/changelog/CHANGE_INDEX.md`: compact index of changelog entries

## Purpose

Use changelog entries to record:

- what changed
- which issue the change belongs to
- which related files were touched

## Notes

- Follow `cortex/changelog/format.md` for the canonical changelog format and index rules.
