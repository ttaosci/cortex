# Issue Tracking

`$CORTEX_HOME/issues/` is the execution system inside Cortex.

It tracks planned work, active work, and completed work.

## Structure

- `$CORTEX_HOME/issues/active/`: issues that are currently being worked on, including issues with `Status: blocked` after execution has started
- `$CORTEX_HOME/issues/backlog/`: issues that are planned and defined but not yet being executed
- `$CORTEX_HOME/issues/closed/`: issues that are finished

## Notes

- Follow `references/workflow.md` for the issue lifecycle and state transitions.
- Follow `references/issue_format.md` for the canonical issue format and field rules.
