# Changelog

Use this directory to record meaningful repository and workflow changes over time.

## Structure

- `$CORTEX_HOME/changelog/entries/`: full changelog entry files
- `$CORTEX_HOME/changelog/CHANGE_INDEX.md`: compact index of changelog entries

## Purpose

Use changelog entries to record:

- what changed
- which issue the change belongs to
- which related files were touched

## Notes

- Follow `references/changelog_format.md` for the canonical changelog format and index rules.
